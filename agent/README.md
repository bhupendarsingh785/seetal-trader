# Seetal Agent — mera apna kaam karne wala hissa

## Kaise aadesh dete hain
`agent/orders.md` kholo aur neeche naya kaam likh do (ek line, `- [ ]` se shuru).
Agent har 2 ghante khud chalta hai, orders padhta hai, kar sakne wale kaam karta hai,
aur `agent/reports/` me nateeja likh deta hai.

## Kya khud kar sakta hai (bina poochhe)
- tests chalana (`tests/check-all.sh`) aur report
- data/live.json ki umar check karna
- saari sites ka health check
- purane reports saaf karna (7 din se purane)
- apni report likhna

## Kya NAHI karta (ye pakka)
- kisi aur ke account/credentials ko chhoona
- kisi platform ke terms todna ya spam/abuse
- paisa, delete, ya public post — bina Swag ki saaf haan ke
- koi aisa kaam jo kanoon ke khilaf ho

Ye "red line" uski apni suraksha ke liye hai, kamzori nahi.

## Chalane ka tareeka
GitHub → Actions → **Seetal Agent** → Run workflow
Ya apne aap: har 2 ghante.
