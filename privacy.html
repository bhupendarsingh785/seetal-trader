Privacy Policy — Seetal

Last updated: 11 November 2026 · App: Seetal (io.github.bhupendarsingh785.seetal)

Chhota jawab: Seetal aapka data aapke phone me rakhta hai. Hamare paas koi server nahi hai jo aapka personal data jama kare. Koi ads nahi, koi tracking nahi, koi data bechna nahi.

1. Hum kya jama karte hain

  • Kuch nahi — app kholne par naam, email ya phone number nahi maanga jata.
  • Notes, Vault ke password, settings — sab aapke phone ke local storage me rehte hain.
  • Agar aap Sync feature use karte ho, to aapka data hamare database (Supabase) par chala jata hai — lekin sirf aapke banaye gaye secret code ke andar. Bina code koi use nahi padh sakta.

2. Internet se kya aata hai

  • Market data — public sources se live price (NSE symbols). Ye data public hai.
  • AI jawab — agar aap AI feature use karte ho, aapka sawal us AI provider ko jata hai jiski key aapne daali hai. Hum us sawal ko store nahi karte.
  • Koi analytics, koi fingerprinting, koi third-party ad SDK nahi.

3. Permissions

  • Microphone — sirf tab jab aap khud voice button dabao (Suno feature). Bina dabaye kuch record nahi hota.
  • Internet — market data, AI aur sync ke liye.
  • Camera, contacts, location, SMS, call — nahi maange jate.

4. Aapka control

  • App ke andar se apna data kabhi bhi delete kar sakte ho (Notes/Vault me delete).
  • App uninstall karne par phone ka saara local data chala jata hai.
  • Sync ka code badal do to purana data aapke naye device par nahi aayega.

5. Bachchon ki privacy

App 18+ ke liye hai (market aur password vault ki wajah se). Hum jaan-boojh kar bachchon se data nahi lete.

6. Financial disclaimer

Trader feature sirf information deta hai — koi order nahi lagta, koi paisa nahi lagta, koi brokerage account nahi jodta. Ye investment advice nahi hai. Market me risk hota hai; faisla aapka aur aapke advisor ka.

7. Badlav

Agar ye policy badlegi, isi page par nayi date ke saath likha jayega.
